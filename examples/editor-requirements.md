# 团队编辑器选型需求

## 项目背景

我们正在开发一个面向中文研发团队的知识管理工作台。前端采用 React、TypeScript 和 Next.js，需要接入可以编辑项目说明、技术方案与调研结论的富文本编辑器。

## 必须满足

- 支持 React 和 TypeScript，核心 API 有公开文档与类型定义。
- 支持中文输入法；输入组合阶段不能错误提交、吞字或跳动光标。
- 支持标题、列表、代码块、链接和基础表格。
- 可以把内容导出成 Markdown，供版本管理与跨工具迁移。
- 可以根据团队设计系统调整工具栏与内容样式。
- 需要明确开源许可证及商业产品使用条件，不能仅依据仓库 Star 数作判断。

## 需要核实

- Next.js 中服务端渲染与客户端编辑器初始化的边界。
- 长文档编辑性能、扩展机制，以及团队必须自行实现的功能。
- GitHub Issue 是否存在与中文输入、React 集成和 Markdown 导出有关的问题；Issue 状态并不直接证明问题已经解决。
- 最近发布与维护情况。仓库数据应注明查询时间，不能将演示夹具当作实时维护数据。

## 输出要求

请给出需求匹配情况、主要接入风险、需要验证的事项和参考来源。资料不足的条目应标记“待核实”，不要补写不存在的结论。
